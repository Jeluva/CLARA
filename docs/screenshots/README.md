# Capturas

Acá van las capturas finales de cada pestaña (Portfolio, Noticias, Research,
Macro, Ingreso de datos) para el README y el contenido de publicación.

Para generarlas: levantar backend (`uvicorn`) + frontend (`npm run dev`),
abrir `http://localhost:5180/` y capturar cada pestaña. El contraste entre el
shell vacío de la Fase 0 y la vista pulida final es el corazón de la narrativa
de "building in public" — conviene guardar también las capturas tempranas.
